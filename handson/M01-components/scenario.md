# モジュール 1: AWS 上の生成 AI アプリケーションのコンポーネント - ハンズオンシナリオ

## シナリオ概要

あなたは、旅行系スタートアップのアプリケーションデベロッパーです。
「ユーザーの質問に自然言語で答える旅行アシスタント」を生成 AI で作ることになりました。
本格的な実装に入る前に、まずは生成 AI アプリケーションを構成する**基本コンポーネント**を理解し、
AWS のどのサービスがどの役割を担うのかを整理します。

このモジュールでは、コードを書く前に「全体像」をつかむことに集中します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **生成 AI の基本概念を理解する**: 基盤モデル（FM）・推論・コンテキストの関係を体感する
2. **AWS 生成 AI スタックを把握する**: アプリ層 / モデル・ツール層（Bedrock）/ インフラ層（SageMaker AI）の役割を整理する
3. **基本アーキテクチャを設計する**: フロントエンド・アプリケーションロジック・FM インターフェイス・FM の 4 つの主要コンポーネントを理解する
4. **オプションコンポーネントを理解する**: メモリ・ベクトルストア・エージェントなどが「いつ必要になるか」を判断できる
5. **最小構成のアプリを動かす**: Bedrock の Converse API を使って、最小の生成 AI アプリを実行する

## AWS 生成 AI スタック

```
┌──────────────────────────────────────────────────────────────┐
│ アプリケーション層                                              │
│   Amazon Quick Suite / Amazon Q Developer / Kiop（IDE）        │
├──────────────────────────────────────────────────────────────┤
│ モデルとツール層                                                │
│   Amazon Bedrock（250+ モデル）/ Amazon Bedrock AgentCore      │
├──────────────────────────────────────────────────────────────┤
│ インフラストラクチャ層                                          │
│   Amazon SageMaker AI / AWS Trainium / AWS Inferentia          │
└──────────────────────────────────────────────────────────────┘
```

## 生成 AI アプリケーションの主要コンポーネント

```
        ┌─────────────────────┐
ユーザー →│ アプリケーション      │
        │ フロントエンド        │
        └──────────┬──────────┘
                   ▼
        ┌─────────────────────┐
        │ アプリケーションロジック │
        └──────────┬──────────┘
                   ▼
        ┌─────────────────────┐
        │ FM インターフェイス    │  ← Amazon Bedrock Converse API
        └──────────┬──────────┘
                   ▼
        ┌─────────────────────┐
        │ 基盤モデル (FM)        │  ← Amazon Nova / Claude
        └─────────────────────┘

  オプション: メモリ / ベクトルストア（RAG）/ エージェント / ガードレール
```

## 使用する AWS サービス

- Amazon Bedrock（Converse API / Amazon Nova）
- （概念理解）Amazon Bedrock AgentCore、Amazon SageMaker AI
