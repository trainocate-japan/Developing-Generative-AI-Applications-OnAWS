# モジュール 8: 責任ある AI の実装 - ハンズオンシナリオ

## シナリオ概要

あなたは、社内向け生成 AI チャットボットのセキュリティ・コンプライアンス担当です。
チャットボットが「不適切なトピックに応答する」「個人情報 (PII) を漏らす」「プロンプト
インジェクションで乗っ取られる」といったリスクに対応するため、**Amazon Bedrock Guardrails** を
導入して、入力と出力の両方に一貫した安全対策を実装します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **責任ある AI のリスクを理解する**: 信憑性・有害性・知的財産・データプライバシー
2. **Guardrail を作成する**: コンテンツフィルター・拒否トピック・単語フィルター・PII フィルター
3. **Guardrail をテストする**: `ApplyGuardrail` API で入出力を評価する
4. **プロンプト悪用に対処する**: プロンプトインジェクション/リークへの多層防御を理解する
5. **決定論的制御と確率的制御を区別する**: どちらで対処すべきかを判断する

## Guardrail のポリシー

| ポリシー | 役割 |
|---------|------|
| コンテンツフィルター | 有害コンテンツ（憎悪・侮辱・性的・暴力など）を強度別にブロック |
| 拒否トピック | アプリで扱いたくないトピックを自然言語で定義してブロック |
| 単語フィルター | 特定の単語・フレーズ・冒涜語をブロック |
| 機密情報フィルター | PII（メール・電話番号など）をブロック/マスク |
| プロンプト攻撃検出 | プロンプトインジェクションを検出 |

## 制御の分類

| 種類 | 概要 | 例 |
|------|------|-----|
| 決定論的制御 | ルールベースで確実に判定 | ユーザーの権限チェック、単語フィルター |
| 確率的制御 | モデルベースで文脈判断 | 有害コンテンツ・バイアスの検出 |

## 使用する AWS サービス

- Amazon Bedrock Guardrails（`bedrock` / `bedrock-runtime` の `ApplyGuardrail`）
- Amazon Nova Lite（応答生成）

## 所要時間

約 45 分

- AWS CLI 設定済み / Python 3.12+
- モデルアクセス有効化済み: Amazon Nova Lite
- Guardrails 作成・実行の IAM 権限
